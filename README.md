# covscript-darwin

Cross-platform terminal UI (TUI) framework for Covariant Script.

> **Note**: Despite the name, "Darwin" is the framework name — it works on Windows, Linux, and macOS. It is not related to Apple Darwin OS.

## Dependencies

- [Covariant Script](https://github.com/covscript/covscript)

## Build

```bash
mkdir build && cd build
cmake ..
cmake --build .
```

## Features

- Pixel-based drawing with color support
- Drawable objects (shapes, text, images)
- UI elements and widgets
- Keyboard input handling
- Timer and animation support
